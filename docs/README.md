# docs/

Documentação do projeto **LP with VR**.

## Estrutura

```
docs/
└── vault/          # Vault do Obsidian (abrir esta pasta no Obsidian)
```

## Como abrir

1. Abra o Obsidian
2. `Open folder as vault`
3. Selecione `docs/vault`
4. Comece por `Home.md`

> Toda a documentação viva do projeto fica dentro do vault. Este README existe apenas
> para explicar o ponto de entrada.
